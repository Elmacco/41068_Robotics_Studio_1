# 41068 Robotics Studio 1

Personal repository for ROS 2 laboratory work, assignments and notes.

## Structure

```
41068_robotics_studio_1/
  ros2_ws/
    src/          ← ROS 2 packages go here
    build/        ← generated by colcon, gitignored
    install/      ← generated by colcon, gitignored
    log/          ← generated by colcon, gitignored
  notes/
```

## ROS 2 version

ROS 2 Humble (installed at `/opt/ros/humble/`)

## Setup (first time on a machine)

ROS 2 Humble must already be installed. Add the following to `~/.bashrc`:

```bash
source /opt/ros/humble/setup.bash
export ROS_LOCALHOST_ONLY=1

# Switch ROS 2 subject workspace: ros_ws <subject_folder_name>
ros_ws() {
    local ws=~/subjects/$1/ros2_ws/install/setup.bash
    if [ -f "$ws" ]; then
        source "$ws"
        echo "Switched to $1"
    else
        echo "No built workspace found at $ws"
        echo "Run 'colcon build' from ~/subjects/$1/ros2_ws/ first"
    fi
}
```

Then pull this repo and build the workspace:

```bash
git clone git@github.com:Elmacco/41068_Robotics_Studio_1.git ~/subjects/41068_robotics_studio_1
cd ~/subjects/41068_robotics_studio_1/ros2_ws
colcon build
```
